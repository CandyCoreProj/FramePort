ข้อมูลสั้น ๆ ที่ช่วยให้เริ่มต้นได้อย่างมั่นใจ

ต้องใช้ Windows รุ่นไหน?

FramePort รุ่นนี้สร้างมาสำหรับ Windows x64 ใช้ได้ทั้งแบบ Setup และ Portable

ทำไมเปิดครั้งแรกต้องดาวน์โหลดเครื่องมือเพิ่ม?

FramePort ติดตั้ง yt-dlp สำหรับดาวน์โหลดและ FFmpeg สำหรับแปลงไฟล์เมื่อเริ่มใช้งานครั้งแรก เพื่อไม่รวมเครื่องมือขนาดใหญ่ไว้ในตัวติดตั้งหลัก

ต้องมีการ์ดจอแยกหรือไม่?

ไม่จำเป็น FramePort ใช้ CPU ได้ และจะลองใช้ตัวเข้ารหัส GPU ที่รองรับเมื่อฮาร์ดแวร์กับไดรเวอร์พร้อม

ไฟล์วิดีโอจะใหญ่ไหม?

ดาวน์โหลดได้จากทุกเว็บไซต์หรือไม่?

FramePort ใช้ yt-dlp และการรองรับขึ้นอยู่กับเว็บไซต์และรุ่นของ yt-dlp โปรดดาวน์โหลดเฉพาะเนื้อหาที่คุณมีสิทธิ์ใช้งาน
